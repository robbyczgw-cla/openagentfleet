## What's new

### Living teammates

- Sidebar presence: idle, working, on computer, needs approval, needs takeover, collaborating, failed
- Pin, unread, hide
- Desktop notifications on finish / fail / approval (Linux `notify-send`, macOS Notification Center)
- Approve / Deny / Stop / Open Agent in the app stay in charge
- Review panel: pending approvals, then each Agent’s last finished run (including blocked)

### Routines

- Create from an enabled Skill; create always starts disabled
- botd claims once, runs a visible Agent turn, 15-minute lease, then advances next-run
- Test-run does the work now without burning the schedule
- Signed loopback webhook on `:4319`; secret shown once, hashed at rest
- Request body is discarded, not injected into the prompt
- Always-approval still waits for Allow

### Phone

- Pair iPhone or Android over private Tailscale (QR or JSON)
- Controller: approvals, stop, pause/enable routines
- Observer: read-only
- No Funnel, no cloud relay, no push

### Windows

- botd and the Go suite run on Windows
- Agent Computer guest stays Linux (`/workspace`)
- Default runtime is Docker Desktop; not started until you ask
- This installer does not prove Computer View on Docker Desktop WSL2

### Also in this source line

- Group chat, mention-gated sends
- Opt-in Agent-to-Agent tools
- Fleet Host loopback pairing (`authority`)

## Install

**Debian / Ubuntu**

```sh
sudo apt install ./OpenAgentFleet_0.3.0_amd64.deb
sudo apt install -y docker.io
sudo usermod -aG docker "$USER"
sudo systemctl enable --now docker
```

Log out and back in so the docker group applies. Opening the app does not start a container.

**Windows**

Run the NSIS installer as the current user. SmartScreen may warn: unsigned publisher. Docker Desktop is optional and only needed for Computer View.
