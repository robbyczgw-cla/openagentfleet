# OpenAgentFleet v0.3.0-alpha

Local-first AI coworkers with a computer you can watch. This alpha adds live
teammates, a routines scheduler, a phone control surface, a Review panel, and
the first Windows host build.

**Not production-ready.** Unsigned Linux and Windows packages. The notarized
Mac download is still [v0.2.0-alpha](https://github.com/robbyczgw-cla/openagentfleet/releases/tag/v0.2.0-alpha).

## What is new

**Living teammates.** The sidebar shows whether an Agent is idle, working, on
the computer, waiting for approval, waiting for takeover, collaborating, or
failed. Pin, unread, and hide work like a chat roster. When an Agent finishes
or needs you, Linux and macOS fire a desktop notification; Approve / Deny /
Stop / Open Agent in the app still decide.

**Review.** One panel lists every pending approval, then each Agent’s last
finished run. Blocked harness runs show up there too.

**Routines that actually run.** Enable a Routine from an enabled Skill. botd
claims the occurrence once, starts a visible Agent turn, renews a 15-minute
lease, then advances next-run. Test-run does the work now without burning the
schedule. A signed webhook on loopback `:4319` can fire the same path. The
secret is shown once. Always-approval still waits for Allow.

**Phone.** Scan the pairing QR (or paste the JSON). A controller phone can
approve, stop, and pause/enable routines. Observer stays read-only. No Funnel,
no cloud relay, no push.

**Windows.** The Go controller and tests run on Windows. The Agent Computer
guest is still Linux (`/workspace`). Docker Desktop is the default runtime and
is not started until you ask. This installer does not prove Computer View
against Docker Desktop WSL2.

**Group chat and Fleet Host** from the 0.3.0-alpha source line are included:
opt-in Agent-to-Agent tools, mention-gated group sends, and an always-on
loopback host for pairing.

## Install

**Debian / Ubuntu**

```sh
sudo apt install ./OpenAgentFleet_0.3.0_amd64.deb
sudo apt install -y docker.io
sudo usermod -aG docker "$USER"
sudo systemctl enable --now docker
```

Log out and back in so the docker group applies. Opening the app does not
start a container.

**Windows**

Run the NSIS installer as the current user. SmartScreen may warn: unsigned
publisher. Docker Desktop is optional and only needed for Computer View.

## What this release does not claim

- A signed or notarized Mac `0.3.0` DMG
- Authenticode or Microsoft Store
- Intel Macs
- Live Computer View on Windows Docker Desktop
- Push notifications or public Tailscale Funnel
- Production stability

Linux packages were built on GNU/Linux from `f812d5d`. The Windows NSIS
installer was built on Win11 x86_64 (dockurr guest) from the same app tree
plus the Git Bash packaging fixes in this tag. OpenCode sidecar is `1.18.10`.
Neither Linux nor Windows packages are signed.
