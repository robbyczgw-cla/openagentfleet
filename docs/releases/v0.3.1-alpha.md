## What's new

- Computer View overlay has **Start Agent Computer** when the guest is stopped. Preview no longer opens a Start-less overlay.
- Onboarding footer stays clickable on 1280x800 Windows with a ~48px taskbar.
- Windows/Linux voice copy does not claim on-device Mac dictation.
- Docker Desktop/wincred errors keep the full text (including German `Anmeldesitzung`) and Retry.
- Appearance palettes, roomy density, font scale, corners, reduce-motion.
- Agent Computer CPU/RAM/disk/swap/OS image sit in Settings, not a collapsed Advanced block.
- Android companion: real screens (Chat, Computer, Routines, Settings), system theme, QR pairing.

## Honest claims

- Computer View on Docker Desktop WSL2 **failed live QA 2026-08-25**. A Windows service in Running is not enough; `Docker Desktop.exe` must be open as the signed-in user.
- `ubuntu:24.04` Hub pull without login is unproven on that box.
- This tag does **not** include the Agent runtime foundation work (EngineAdapter / Tool Registry / ComputerBackend).
- No Funnel, push, or cloud relay.

## Install

Same as `v0.3.0-alpha`. Opening the app does not start Docker or a VM.
